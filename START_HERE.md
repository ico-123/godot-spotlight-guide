# Start Here

1. Open this extracted folder as a Godot 4.7.2 or newer project and press
   `F5`.
2. To use the addon in another project, copy `addons/spotlight_guide` into that
   project's `addons/` directory.
3. Enable **Spotlight Guide** under **Project Settings > Plugins**, then add a
   `SpotlightGuide_Overlay` node and assign a `SpotlightGuide_Sequence`.

Read `README.md` and `docs/INSTALL.md` for complete setup instructions.
